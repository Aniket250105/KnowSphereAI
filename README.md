# KnowSphere AI

KnowSphere AI is a general-purpose AI Knowledge Assistant. It allows users to upload documents (PDF, DOCX, PPTX, TXT, Markdown) and chat with them using Retrieval-Augmented Generation (RAG). 

## Project Vision
Designed to be scalable and versatile, KnowSphere AI is suitable for education, enterprises, healthcare, legal, research, and personal knowledge management.

### Current Development Phase
Phase 1: Project Initialization and Architecture Setup.

### Future Features
- Document Upload & OCR Support
- Text Extraction & Chunking
- Embedding Generation
- Vector Database Integration (Qdrant)
- Semantic Search
- Llama 3 Integration & LoRA Fine-tuning
- Gradio UI & FastAPI Backend
- Multi-user Support & Authentication
- Docker Deployment

## Architecture Overview
This project uses a clean, modular Python architecture separating API, services, domain logic, and data layers to support scalable future expansions seamlessly.
